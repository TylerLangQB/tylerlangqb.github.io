# Tyler Lang Recruiting Website

A static recruiting hub for Tyler Lang, Class of 2030 QB at Hickory Grove Christian, North Carolina.

## Included
- `index.html` — comprehensive player/recruiting homepage
- `stats.html` — statistics page
- `game-log.html` — game log
- `recruiting.html` — recruiting profile
- `robots.txt` and `sitemap.xml`

## Publish
Upload the contents of this folder to any static web host and point a domain such as `tylerlangqb.com` to it. Replace the canonical URLs in the HTML/sitemap if using another domain.

## Updating after each game
Update the verified season total, game log, date and any verified film link. Do not estimate missing yardage/TD numbers or claim rankings/offers that have not been published by the relevant source.

## SEO
The homepage uses a descriptive title/description, canonical URL, Open Graph metadata, and ProfilePage/Person structured data. Google documents ProfilePage structured data here: https://developers.google.com/search/docs/appearance/structured-data/profile-page
